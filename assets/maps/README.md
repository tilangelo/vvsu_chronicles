# Ранние рисунки первого этажа

В папке три приблизительных рисунка сверху и исходная расшифровка пользователя [plan_1_floor.md](plan_1_floor.md): вестибюль, коридор первого этажа и продолжение.

Это материалы планировки без масштаба. Вход/зимний сад/четвёртый этаж затем уточнялись пакетом из ../план/, **а коридор первого этажа восстановлен и доработан по ранним рисункам**. Сейчас он активен и связан с отдельными аудиториями, туалетами, отдыхом и лестницей №2 в зимний сад. Поэтому прежняя фраза «ранние рисунки больше не используются» не описывает текущую версию.

Нумерация в plan_1_floor.md — исходные пояснения к рисункам, не список ещё не выполненных задач. Точные игровые координаты/входы задают ../../game/maps/corridor_1.json и карты отдельных помещений.

Статус всех источников и приоритет документов — [../README.md](../README.md).
