# Интеграция: люди, интерфейс, анимация

Инструкция для человека или нейросети, которая встраивает эти файлы в проект Godot 4.7. Проект лежит в папке `godot_4_7`, все пути ниже даны от неё.

## Сначала

Проект ни разу не запускался в Godot: на компьютере автора его нет. Первым делом откройте проект в редакторе, дождитесь импорта и запустите его клавишей F5. Ошибки вероятнее всего появятся в `scripts/level.gd`, `scripts/dialog_box.gd` и `tileset.tres`. Сортировку людей и тайлов проверьте глазами: она собрана по превью, а не по запуску.

Сюжета и текстов диалогов в файлах нет. Кто что говорит и в каком порядке, задаётся отдельно.

| Что | Где | Как работает |
|---|---|---|

Что не подключено и остаётся за вами: расстановка людей (`npcs` на всех картах пуст), открытие дверей и турникетов при подходе, запуск диалогов.

## Система координат

- Клетка `(x, y)` на карте, `(0, 0)` дальняя. Ось `x` идёт на экране вправо-вниз, ось `y` влево-вниз.
- Стороны у людей экранные: `s`, `se`, `e`, `ne`, `n`, `nw`, `w`, `sw`.
- Вдоль осей карты: `+x` это `se`, `+y` это `sw`, `-x` это `nw`, `-y` это `ne`.
- Что можно проходить, написано в `maps/legend.json` по символам `rows`.

## Как поставить человека

Добавьте запись в список `npcs` нужной карты в `maps/<id>.json`:

```json
{ "who": "guard", "x": 19, "y": 11, "facing": "sw", "pose": "idle" }
```

| Поле | Значение |
|---|---|
| `who` | id из `maps/characters.json` |
| `x`, `y` | клетка, человек встаёт в её центр |
| `facing` | сторона. Для `sit` и `type` только `se`, `sw`, `ne`, `nw` |
| `pose` | `idle`, `walk`, `sit`, `type` |
| `lift` | необязательно, подъём картинки в пикселях. По умолчанию берётся `elevation` клетки |
| `path` | необязательно, список клеток `[[x, y], ...]`. Человек ходит по ним по кругу со скоростью 2 клетки в секунду |

Человек без `path` занимает клетку, герой через него не пройдёт. Идущий человек клетки не занимает. Людей на нижнем уровне андера видно и из галереи, но двигаются они только на своей карте.

Готовый пример для всех пяти карт: `maps/npcs_example.json`, по нему собраны картинки `preview_people_*.png`. Записи можно копировать прямо в карты.

### Места, где человек сидит

| Тайл | Где | `facing` | `pose` |
|---|---|---|---|
| `chair_w` | нижний уровень андера, `x` = 34, 38, 42, 46; `y` = 21, 23 | `se` | `sit` |
| `chair_e` | нижний уровень андера, `x` = 36, 40, 44, 48; `y` = 21, 23 | `nw` | `sit` |
| `class_chair_north` | класс, `x` = 2–5, 7–10; `y` = 1, 4 | `sw` | `type` |
| `class_chair` | стол преподавателя, клетка (3, 8) | `ne` | `type` |
| `bench_x` | вход (7–9, 11), (12–14, 11); коридор (11, 12, 20, 21, 33, 34; 0); андер (33–35, 14), (44–46, 14) | `sw` | `sit` |

Клетку стула нельзя пройти, поэтому человек на стуле ничего не перекрывает. На `bar_stool` сидячей позы нет: он намного выше обычного стула.

### Места за стойками

| Кто | Клетки | Запись |
|---|---|---|
| Гардеробщица | вход, `y` = 2, `x` = 3, 8, 13, 18: там нарочно нет вешалок | `"facing": "sw"` |
| Бариста | андер, `y` = 35–36, `x` = 19–25 | `"facing": "ne", "lift": 16` |
| Повар | нижний уровень, `y` = 26, клетки с тайлом `kitchen_floor` | `"facing": "ne"` |
| Охранник | вход (19, 11), андер (9, 6) | `"facing": "sw"` |

В будку охраны человека лучше не ставить: стены будки и её пол нарисованы одним тайлом, и сортировка не даст поставить его между ними.

## Листы персонажей

`assets/characters/<id>.png`, 320×960, кадр 64×96, ступни в точке (32, 88). Описание в `maps/characters.json`.

| Строка | Содержимое |
|---|---|
| 0–7 | стороны `s, se, e, ne, n, nw, w, sw`: столбец 0 стойка, столбцы 1–4 ходьба |
| 8 | сидит: столбцы 0–3 это `se, sw, ne, nw` |
| 9 | сидит за компьютером: те же столбцы |

Люди: `hero`, `guard`, `wardrobe`, `teacher_m`, `teacher_f`, `barista`, `cook`, `mentor`, `student_1` … `student_8`. Портреты есть у всех, кроме студентов: `assets/portraits/<id>_normal.png` и `<id>_smile.png`, 128×128, показывать при ×2.

## Диалог

В `level.gd` есть переменная `dialog`:

```gdscript
dialog.show_line("guard", "Пропуск покажите, пожалуйста.")
await dialog.line_finished
dialog.show_line("hero", "Я первокурсник, вот студенческий.", "smile")
await dialog.line_finished
dialog.show_choices(["Спросить дорогу", "Пройти дальше"])
var answer: int = await dialog.choice_made
dialog.close()
```

`show_line` ждёт Enter или пробел. Первое нажатие показывает текст целиком, второе идёт дальше. Для студента окно откроется без портрета, имя возьмётся из `characters.json`. Текст идёт стандартным шрифтом Godot, он должен показывать кириллицу.

## Двери и турникеты

Кадры лежат в строках `strips` файла `maps/anim.json`: `door_x_open`, `door_y_open`, `glass_door_x_open`, `glass_door_y_open`, `turnstile_gate_open`. Кадр 0 закрыт, кадр 3 открыт.

```gdscript
play_strip("walls", Vector2i(14, 0), "door_x_open")        # открыть
play_strip("walls", Vector2i(14, 0), "door_x_open", true)  # закрыть
```

На картах обычные двери закрыты (`door_x_open_0`, `door_y_open_0`), дверь в класс 1421 открыта (`door_x_open_3`). Стеклянные двери стоят обычными тайлами, их кадр 0 выглядит так же. Турникеты стоят в слое `props`, поэтому для них первый аргумент `"props"`. На карте проход открыт и руки нет. Чтобы он начинался закрытым, поставьте в клетку прохода тайл `turnstile_gate_open_0`.

## Анимация по кругу

Тайлы `aquarium_anim_0..2`, `turnstile_anim`, `turnstile_gate_anim`, `led_cut_anim`, `kiosk_terminal_anim`, `coffee_bar_machine_anim`, `class_tv_y_anim`, `class_teacher_pc_anim` уже стоят на картах и играют сами. В `tiles.json` у них есть поле `"source": 1`.

Что видно не полностью: мониторы студентов повёрнуты от камеры, поэтому мерцают только телевизоры на стене и монитор преподавателя. LED-экран стоит в срезанной стене, анимация видна на его низком обрезе.

## Интерфейс

Картинки в `assets/ui` сохранены с пикселем ×2 и используются 1:1 при окне 1280×720. Отступы для растяжения: `dialog_panel` 16, `button_*` и `name_plate` 14, `choice_*` 10. Готовые стили дают функции `UiKit.button()` и `UiKit.choice()` из `scripts/ui_kit.gd`.

## Экспорт

JSON читается при запуске. Для экспорта игры добавьте `*.json` в фильтр файлов экспорта.
