# Проверка текущего среза

В [snapshot.json](snapshot.json) сохранены дата, версия Godot, показатели карт и результаты десяти проверок, относящихся к описанным игровым сценариям. Отдельные журналы содержат вывод этих проверок.

Хеши охватывают скрипты, перечисленные в game/README.md, а также карты, сцены, PNG и файлы настроек проекта. Они предназначены для сверки описанных частей и не являются перечнем всех файлов проекта.

Покрытие, команды и ограничения — [../../VALIDATION.md](../../VALIDATION.md); иллюстрации — [../../screenshots/README.md](../../screenshots/README.md). Если проект изменится, повторите проверки и укажите дату нового среза.
