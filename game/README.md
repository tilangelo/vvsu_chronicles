# Активный Godot-проект

Актуально: 2 ноября 2026. Это рабочий проект; исходные демонстрации в соседней папке assets не следует запускать вместо него.

Godot 4.7.2 Standard / GDScript / Compatibility. Открыть project.godot → F5 → «Начать». Главное меню — scenes/menu.tscn; игровая сцена — scenes/main.tscn; corridor.tscn является совместимым алиасом main.tscn.

## Игровой срез

12 локаций, 25 направленных зон перехода, 83 размещения NPC, 6 маршрутов ходьбы. Первый день: 12:40, 500 ₽, куртка/номерок №27, наставник → оплата бейджика 150 ₽, пара в аудитории 1421 в 13:30.

Задания независимы, переходы сохраняют прогресс текущей сессии. Пауза и диалоги останавливают время; масштаб ×10. Приход заранее требует ожидания; опоздание отмечается. Новый запуск сбрасывает день, сохранения на диск нет.

WASD/стрелки/стик — ходьба; E/Enter/A — действие по подсказке; стрелки + Enter/A — ответ; Esc — закрыть диалог/пауза; колесо/+− — масштаб.

## Активные модули

| Файл scripts/ | Ответственность |
|---|---|
| level.gd | Сборка карт, игровой цикл, герой/камера/ввод, переходы, взаимодействия и координация UI |
| route_map.gd | Список карт, JSON, сеточная проходимость и границы стен |
| campus_day.gd | Часы, баланс, флаги заданий, посещение пары, одноразовые действия |
| campus_dialogue.gd | Условные приветствия, темы, варианты ответов |
| quest_tracker.gd | Компактный HUD часов, денег и заданий |
| campus_people.gd | Создание людей, сортировка, маршруты и выбор собеседника |
| person.gd / character_visual.gd | Листы персонажей и адаптер движения героя |
| environment_animation.gd / door_visual.gd | Циклы окружения, открытие турникетов/дверей |
| menu.gd / ui_kit.gd / dialog_box.gd | Меню, стили, портреты, печать, страницы и ответы |
| arch_visual.gd / atm_visual.gd / fixture_visual.gd | Дополнительные объекты, нарисованные геометрией Godot |

**Неактивные:** corridor.gd, player.gd, walk_visual.gd. Они оставлены как история ранних реализаций, не описывают текущий игровой цикл.

## Данные и ресурсы

- maps/<id>.json — геометрия, предметы, NPC, переходы, дополнительные объекты.
- maps/legend.json — свойства символов сетки; tiles.json — каталог тайлов.
- maps/characters.json — 16 листов персонажей, включая героя; npc_lines.json — темы/приветствия.
- maps/anim.json — 10 циклов и 5 полос анимации.
- maps/npcs_example.json — пример из набора, **не загружается игровым кодом**.
- assets/characters, portraits, ui и два PNG-атласа — активная графика.
- tileset.tres — статический источник 0; анимированный источник 1 создаётся кодом.
- assets/hero_temp.png — старый ресурс, активный герой его не использует.

Схемы и связи — [архитектура](../docs/ARCHITECTURE.md), происхождение графики — [assets/README.md](assets/README.md).

## Проверки

Из корня game/ с настроенной командой Godot:

```powershell
& $godotExe --headless --path '.' --script res://tools/check_day_quests.gd --quit-after 600
& $godotExe --headless --path '.' --script res://tools/check_people_update.gd --quit-after 600
& $godotExe --headless --path '.' --script res://tools/check_route.gd --quit-after 600
```

Полный набор из девяти сценариев: [VALIDATION.md](../docs/VALIDATION.md). Это скриптовые проверки движка; они не подтверждают производительность на целевом неттопе и не заменяют визуальную приёмку.

Готового профиля экспорта нет. При его настройке включить JSON-ресурсы; см. [SETUP.md](../SETUP.md).
